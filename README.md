# SchematicGatherer

Мод для Fabric (Minecraft 26.1): указываешь файл схематики — бот сам собирает все ресурсы.
Строить он не умеет (и не должен) — только добыча материалов.

Два режима на выбор:

| Режим | Кто копает | Движок | Команда |
|---|---|---|---|
| `#gather` | твой персонаж | [Baritone](https://github.com/cabaletta/baritone) (`#mine`) | клиентская |
| `/gatherbot` | отдельный фейк-игрок | свой серверный мозг (в стиле [Carpet](https://github.com/gnembon/fabric-carpet) `/player`) | серверная, нужен OP |

## /gatherbot — бот-фейкплеер

```mcfunction
/gatherbot spawn Farmer
/gatherbot Farmer list house.schem        — показать список материалов
/gatherbot Farmer gather house.schem      — собирать всё для схемы
/gatherbot Farmer gather house.schem 96   — то же, но радиус поиска 96
/gatherbot Farmer status
/gatherbot Farmer stop
/gatherbot Farmer kill
```

Как это работает:

1. Спавн — как `/player` у Carpet: фейковый игрок с офлайн-UUID и фальшивым соединением,
   для сервера он полноценный игрок (инвентарь, дропы, смерть).
2. Мод сам читает `.schem` (Sponge v2/v3, свой NBT-парсер — Baritone не нужен).
3. Блоки схемы переводятся в «что реально копать» цепочками правил
   (`oak_stairs → oak_planks → oak_log`, `glass → sand`, `bricks → clay` и т.д.),
   недобываемое (bedrock, порталы, спавнеры) пропускается с записью в отчёт.
4. Бот ищет ближайший нужный блок в радиусе, идёт к нему по прямой (прыгает через
   одиночные блоки), выбирает лучший инструмент из хотбара и ломает блок с настоящим
   прогрессом разрушения — как `attack continuous` у Carpet.
5. Дроп подбирается автоматически. Каждая цель — «пока в инвентаре не будет N штук».
6. В конце — отчёт: что собрано, что не найдено в радиусе.

Ограничения мозга v0.2: **нет A*-патфайндинга** — идёт по прямой. Открытая местность и
карьеры — ок; сложные пещеры с обходами — нет. Если не может подойти ~3 секунды,
блок помечается недостижимым и берётся следующий.

## #gather — сбор твоим персонажем через Baritone

```mcfunction
#gather house.schem        — Baritone сам копает всё для схемы (#mine по очереди)
#gather list house.schem   — только показать список материалов
#gather status
#gather stop
```

Тут добычей управляет Baritone (полноценный pathfinding, поиск жил, уклонение от
опасностей). Файл ищется в `schematics/` — как у `#build`.

## Общее

- Схематики клади в папку `schematics/` рядом с игрой.
- То, что уже лежит в инвентаре, вычитается — бот добирает только разницу.
- Крафт и переплавку бот **не делает сам** — добывает сырьё и пишет подсказку
  («переплавка: песок → стекло», «крафт: доски»). Автокрафт — в роадмапе.
- Для `#gather` Baritone копает только то, что уже видел (world cache) —
  для больших объёмов сначала `#explore`.

## Готовый jar без локальной сборки

В репозитории настроен GitHub Actions: каждый пуш собирает мод
(включая Baritone 26.1 из исходников — нужен только на этапе компиляции).
Готовый jar забирай из **Actions → последний запуск build → Artifacts → `schematic-gatherer`**.

## Сборка локально

Нужны **JDK 25** и **Gradle 9.5+** (loom 1.17-SNAPSHOT собран под Gradle 9.5 —
на 9.4 и старше будет ошибка `Could not resolve net.fabricmc:fabric-loom`).

1. (Только для `#gather`) скачай jar Baritone для Fabric из ветки `26.1` и положи в
   `libs/baritone-fabric.jar` — он нужен лишь для компиляции. Если Baritone не нужен,
   удали `SchematicGathererMod.java`, `GatherCommand.java`, `GatherProcess.java`,
   `MaterialCounter.java` и строку `"client": ...` из `fabric.mod.json` —
   соберётся версия только с `/gatherbot`.
2. `gradle build` → jar в `build/libs/schematic-gatherer-0.2.0.jar`.

## Установка

1. Fabric Loader 0.19.3+ для Minecraft 26.1.
2. В `mods/`: Fabric API, этот jar, и (для `#gather`) Baritone.
3. `/gatherbot` работает и в одиночке (с читами), и на сервере (нужен OP).

## Роадмап

1. Автокрафт (верстак 2x2/3x3) по рецептам.
2. Печки: плавка стекла/камня/кирпичей по очереди.
3. Сундуки базы: забрать готовое / сложить добытое.
4. Умное передвижение для `/gatherbot` (A* или баритоноподобный движок).
5. Сохранение инвентаря бота между перезаходами (как Carpet).
6. Связка со стройкой: собрал → `#build` по слоям.
