# SchematicGatherer

Аддон к [Baritone](https://github.com/cabaletta/baritone) для Fabric (Minecraft 26.1):
указываешь файл схематики — бот сам считает все блоки и добывает нужные ресурсы через `#mine`.

```mcfunction
#gather house.schem
```

Строить он не умеет (и не должен) — только собирает материалы.

## Как это работает

1. Парсит схематику через `SchematicSystem` самого Baritone (`.schem`, `.schematic` — всё, что понимает `#build`).
2. Считает каждый блок и складывает в список материалов.
3. Переводит «блок из схематики» в «что реально копать» по цепочкам правил:
   - `oak_stairs → oak_planks → oak_log` (с пересчётом количества: 1 бревно = 4 доски и т.д.);
   - `glass → sand`, `bricks/terracotta → clay`, `stone → камень (выпадет булыжник)` и т.п.;
   - недобываемое (bedrock, барьеры, спавнеры, порталы) честно пропускает и пишет в отчёт.
4. Вычитает то, что уже лежит в инвентаре.
5. По очереди запускает `#mine <блок> <количество>` для каждой позиции,
   следит за инвентарём, при неудаче делает один повтор и идёт дальше.
6. В конце — отчёт: что собрано, что не удалось найти.

## Команды

```mcfunction
#gather <файл>        — начать сбор ресурсов для схематики
#gather list <файл>   — только показать список материалов (ничего не копает)
#gather status        — прогресс текущего сбора
#gather stop          — остановить
```

Файл ищется в папке `schematics/` (как у `#build`). Расширение можно не писать.

## Сборка

Нужны **JDK 25** и **Gradle 9.1+** (для Java 25).

1. Скачай jar Baritone для Fabric из ветки `26.1` (mod версии 1.18.0) —
   официальные сборки с GitHub `cabaletta/baritone` или собери сам.
2. Положи его в `libs/` и назови **`baritone-fabric.jar`** (нужен только для компиляции).
3. Собери:

```bash
gradle build
```

Jar будет в `build/libs/schematic-gatherer-0.1.0.jar`.

## Установка

1. Fabric Loader 0.19.3+ для Minecraft 26.1.
2. В папку `mods/`: Fabric API, Baritone (fabric), `schematic-gatherer-0.1.0.jar`.
3. Зайди в мир и напиши `#gather list <твоя схема>` — проверь, что список материалов считается.

## Ограничения v0.1

- Крафт и переплавку бот **не делает сам** — он добывает сырьё и пишет подсказку
  («переплавка: песок → стекло», «крафт: доски»). Автокрафт — в роадмапе.
- Baritone копает только блоки, которые уже видел (world cache). Для больших объёмов
  сначала прогони `#explore` или просто облети территорию.
- Если блок не найден, позиция пропускается и попадает в финальный отчёт — ничего не зависает.
- Шерсть/бетон/красители: добудет основу, остальное напишет в подсказках.

## Роадмап

1. Автокрафт (верстак 2x2 и 3x3) по рецептам клиента.
2. Печки (плавка стекла/камня/кирпичей по очереди).
3. Сундуки базы: забрать готовое / сложить добытое.
4. Сохранение прогресса сбора между перезаходами.
5. Связка со стройкой: `#gather` → `#build` по слоям.
