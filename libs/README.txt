Сюда положи jar Baritone для Fabric (ветка 26.1) и назови его:

    baritone-fabric.jar

Подойдёт официальный baritone-fabric-1.18.0.jar с GitHub cabaletta/baritone
или любой jar, где есть классы baritone.api.*.
Он нужен только для компиляции (compileOnly) — в игре используется
тот Baritone, что стоит у тебя в mods/.
